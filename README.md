### What I Build

I work in **cybersecurity** and build software **for fun** — mostly focused on reducing attack surface, stripping telemetry, and hardening everyday tools:

- **Hardened Communication Clients** — Zero-telemetry, de-bloated desktop & mobile forks with OPSEC safeguards, RAM-only retention, and relay/anti-fingerprinting controls.
- **Network & Routing Utilities** — Python & TypeScript tools for WAN IP rotation, CGNAT diagnostics, and route optimization.
- **Homelab & Self-Hosted Infrastructure** — Hardened Linux environments, reproducible build pipelines, and local automation.
